# SimCheck Client Data Policy

The public client data policy for SimCheck, the simulator QA service operated by Tellbloom, Inc. (the entity, not its flagship product). It is served by GitHub Pages from `index.html` on `main`.

Every statement in it is a commitment that the QA tool (`cicero-qc`) must keep true: AI training off on the provider accounts, fresh sessions with no saved history, client content outside cloud-synced folders and source control, deletion after 30 days unused (`spikes/workbench/purge.mjs` in `cicero-qc`), and customers told before an AI provider is added or replaced. Change the tool and this page together, and update the effective date when the text changes.
